# BubbleUps! 🔮


> *Un mod para Minecraft Fabric donde las burbujas dejan de ser decoración para convertirse en el centro de una nueva forma de jugar.*

---

![Banner](/media/banner.png)
</div>

## 📖 ¿Qué es BubbleUp?

BubbleUp es un mod que transforma un concepto simple: **las burbujas**, en una nueva forma de interactuar con Minecraft.

Lo que comenzó como una idea sencilla evolucionó hasta convertirse en un sistema donde cada burbuja puede tener un propósito diferente. Algunas pueden ayudarte, otras pueden convertirse en herramientas de combate, y otras pueden cambiar completamente la forma en la que exploras el mundo.

El objetivo de BubbleUp es tomar algo pequeño y simple, y convertirlo en una mecánica con posibilidades propias, creando una experiencia donde la curiosidad y la experimentación son parte del juego.

---

## ✨ ¿Qué añade el mod?

BubbleUp añade un sistema completo de burbujas con diferentes comportamientos, efectos y funciones dentro del mundo.

El mod incorpora:

- ⚗️ Nuevas burbujas y proyectiles con mecánicas propias.
- 🌈 Nuevos efectos originales que amplían la interacción y experiencias con el juego.
- ⚙️ Nuevas mecánicas de juego integradas con la experiencia de Minecraft.
- 🎨 Recursos personalizados creados para complementar el contenido del mod.

El sistema queda preparado para futuras ideas y nuevas formas de utilizar las burbujas.
